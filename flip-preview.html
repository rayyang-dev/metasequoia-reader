设计取舍

留白优先纸永远是纸。墨只落在笔锋扫过的那一带，绝不用色块盖满整屏——中国画的第一原则是留白。
是真笔触沿中轴采样生成变宽封闭轮廓：藏锋钝头 → 铺毫的稳定笔身 → 提笔出锋。不是等宽线条，更不是把一张固定 SVG 拉伸铺满。
墨分五色水痕 / 湿墨 / 笔身 / 浓墨 / 笔心 / 骨线 六层同心叠墨，边缘清淡、笔心焦浓，纸色从墨里透出来。
飞白用 mask 沿笔势挖出丝丝露白，越到收笔越密；露出的是宣纸本身，不是白色颜料。
生宣侧锋几何抖动做出吸墨不匀的毛边，更宽更淡的同心轮廓就是水痕；全程不用 SVG 滤镜，避免 WebView 逐帧重算掉帧。
换页因果旧字被水化开 → 笔锋过半时换页 → 新字由淡到浓自纸纤维渗出，靠「墨色浓淡」过渡，不靠遮盖偷换。
工程Web Animations API 编排约 780ms（旧版 1950ms），绕开全局 animation:none；finally 统一清理墨层、旧页克隆与全部动画，渲染抛错也不留残影；尊重系统「减少动态效果」。
