## 二、必须你在控制台做的 3 件事（我无法代操作）

### 1. 域名实名认证（最先做，否则解析不生效）
- 阿里云控制台 → 域名 → `shanwood.cn` → 实名认证，提交身份证 + 人脸核验。
- **未实名会被 Serverhold 暂停解析**，审核约 1–3 工作日。这一步没过，后面改 NS 也不会生效。
- 顺手开启**自动续费**（按 ¥42 扣，防 `.cn` 忘记续费进赎回期 ¥1200），并在 2027-10 月底设日历提醒，先查双 11 续费活动再决定是否手动续。

### 2. 把域名接入 Cloudflare（拿 NS → 回阿里云改）
1. Cloudflare 控制台 → Add a site → 输入 `shanwood.cn` → 选 Free 计划。
2. 复制分配给你的 **2 个 Cloudflare nameservers**（形如 `xxx.ns.cloudflare.com`）。
3. 阿里云控制台 → 域名 → 管理 → **修改 DNS 服务器 / Nameserver**，替换成这两个。
4. 等 zone 状态从 `Pending Nameserver Update` 变 `Active`（通常几分钟到数小时）。
- 域名在阿里云注册，可以改 NS；若域名是在 Cloudflare Registrar 注册的则**不允许改 NS**（会锁死），本路线成立的前提正是注册商不是 Cloudflare。
- 备注（2026-07 工信部 DNS 服务商资质核查）：**已完成 ICP 备案的商用域名**要求主 NS 用持牌国内服务商，境外 DNS 只能作备用副解析。本项目走免备案路线、不触发该核查；**若将来改走备案路线，需把 NS 换回阿里云/腾讯云 DNS**。

### 3. 建 Cloudflare Pages 项目并绑自定义域

| 子域 | 用途 | 来源 | 备注 |
|---|---|---|---|
| `sequoia.shanwood.cn` | 官网 / 下载 / 隐私政策 | 本仓库 `site/` 目录 | 对齐 appName「红杉阅读」与仓库 `sequoia-reader` |
| `blog.shanwood.cn` | 「Agent 道场」博客 | 工作区 `blog/`（不在本仓库） | Direct Upload 或单独建仓 |
| `dl.shanwood.cn` | APK 直链 / 二维码短链 | Redirect Rule 301 → GitHub Release | 需一条 proxied DNS 记录承载 |
| `shanwood.cn`（裸域） | 建议 301 跳到 `sequoia.shanwood.cn` | Redirect Rule | 主域不直接挂内容 |
| `metasequoia` | **预留不分配** | — | 留给「水杉」树种本身，不要拿来当官网 |

- `site/` 项目：连接 GitHub 仓库 `rayyang-dev/sequoia-reader` → **Root directory = `site`** → Framework preset = None → Build command 留空 → Build output directory 留空（若 Pages 强制要求填则填 `/`）。纯静态，无需构建。
- 自定义域在 **Pages 项目的 Custom domains** 里添加，Cloudflare 会自动写好 CNAME 并签发证书，**不要在 DNS 里手工重复加同名记录**。
- 证书：Pages 自带 Universal SSL，首次签发几分钟；SSL/TLS 加密模式建议 `Full (strict)`。
- 博客 `blog/` 不在本 Git 仓库里，最简单用 `wrangler pages deploy ./blog --project-name=agent-dojo`（Direct Upload），不必为博客单独建仓库。

## 四、两条硬约束（别踩）

1. ❗ **不要为了「加域名」去改 `capacitor.config.json` 的 `server.hostname`**：origin 一变，localStorage（`inkreader:*` 设置 / 进度 / 书签 / 书架 + `inkreader:sw-cache`）与 IndexedDB（书籍正文）全部不可见，等同数据丢失。当前 APK 未绑定任何自有域名，加官网/下载页**不用改 APK、不用发新版**。
2. ❗ **不要改 `applicationId` / appId**：等于换 App，已装用户必须卸载重装且数据全丢。对外品牌统一用 `sequoia`，代码里的 `com.rayyang.metasequoia` 与 APK 资产名 `Metasequoia-vX-release.apk` 原地不动；App Links 的 `assetlinks.json` 只校验签名指纹 + 包名，不要求域名含包名。
