# 水杉阅读 · 能力路线图 200 项（v1.3.0 起）

> 组织方式：**20 个能力簇 × 10 项**。顶级产品团队不会把 200 个点做成 200 个孤立开关，
> 而是归并为「能力系统」——一整套数据结构 + 一套 UI + 一组行为契约覆盖多个点。
> 簇 1–10（1–100 项）见 `roadmap-100.md`；本文件只展开簇 11–20（101–200 项）。
> 优先级：P0 = 体验硬伤 / 高频，P1 = 明显提效，P2 = 长尾或依赖外部条件。
>
> 落地状态见文末「全 200 项落地矩阵」。**未落地项明确标注原因，绝不做「点了没反应」的假开关。**
