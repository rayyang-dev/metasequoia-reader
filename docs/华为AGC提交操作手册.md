## 1. 注册并实名华为开发者账号

1. 打开 `https://developer.huawei.com/consumer/cn/agconnect/`，注册 / 登录华为账号。
2. 进入「开发者联盟 → 实名认证」。**个人开发者**适合本项目（工具类、免费、非经营）。
3. 个人认证：身份证 + 人脸核验（部分情况需银行卡验证），免费，通常 1–3 工作日。
   - 企业认证需营业执照 + 对公信息；**不支持港澳台及海外主体注册中国大陆开发者账号**。
4. ⚠️ **未完成实名认证无法创建应用、无法提交审核**。
5. 认证通过后，记下主体姓名——后续「核准(备案)信息」的主体一致性、版权材料著作权人都必须与它完全一致。
