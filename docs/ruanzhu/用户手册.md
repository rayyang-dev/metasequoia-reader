## 一、软件概述

红杉 Sequoia 是一款**本地优先**的电子书阅读器，面向墨水屏设备与手机/平板优化，强调"纸感排版、零广告、离线可读"。软件支持导入本地 TXT / EPUB / PDF / MOBI / FB2 / HTML / DOCX 等格式，提供宣纸/简约两套阅读主题、可调排版参数、阅读统计与打卡、书签、以及可选的 AI 导读/翻译/问答/笔记能力（需用户自备第三方大模型 Key，全部数据本地优先）。

软件整体为前端单页应用（HTML/CSS/JavaScript），经 Capacitor 封装为 Android/iOS 原生外壳，无中心化后端服务器。

## 二、主要功能模块

1. **书架管理**：导入/删除本地书籍，按文件类型分组展示，支持拖拽与系统文件选择器导入。
2. **阅读器**：分页渲染、章节目录、书签、上一页/下一页、翻页动画与墨水屏整屏刷新（清残影）。
3. **主题与排版**：两套主题（墨水风/简约），字号、行距、边距、段距、字间距、两端对齐、首行缩进均可调。
4. **阅读统计**：日/周/月维度的阅读时长、书目、打卡记录。
5. **AI 引擎（可选）**：翻译、全书/本章导读、书中问答、人物脉络笔记、智能书架标签、段落双语对照；支持 DeepL / Google / 任意 OpenAI 兼容接口。
6. **法律与隐私**：内置隐私政策、用户协议、权限说明。

## 三、运行与操作说明

### 3.1 启动与书架
启动后进入书架页（见 `docs/screenshots/02-shelf-flat.png`），可点击对应格式按钮导入书籍，或从文件系统选择文件/拖拽导入。

### 3.2 阅读界面
点击书籍进入阅读器（见 `docs/screenshots/03-reader.png`）：顶部为章节标题与返回/目录，中部为正文分页区，底部为翻页与工具（书签/AI/目录）。点击屏幕中部可唤出/收起上下栏。

### 3.3 排版与主题设置
进入「设置」（见 `docs/screenshots/04-settings.png` 中的外观/排版分组），可切换主题皮肤、字体、字号、行距、边距、段距、字间距、翻页动画与整屏刷新频率。

### 3.4 选中文字与 AI
在阅读页长按选中文字（见 `docs/screenshots/03-reader.png`），弹出"译 / AI 解释"工具条；或打开 AI 助手面板（见 `docs/screenshots/05-ai-panel.png`、`docs/screenshots/05-ai-panel.png`）生成导读、问答、笔记与双语对照。

### 3.5 阅读统计与打卡
底部切到「统计」查看阅读时长与打卡；当日累计阅读达阈值即自动打卡。

## 四、数据存储说明

所有书籍、进度、书签、设置与（可选的）API Key 均保存在设备本地（浏览器本地存储 / 应用沙盒），不上传任何服务器。启用 AI/翻译时，仅将用户选中的文本或本书内容发送至用户自行配置的第三方接口。

## 五、权限说明

- Android：仅申请"网络（INTERNET）"，用于 AI/翻译与版本检查；书籍导入走系统文件选择器（SAF），不申请存储读写权限。
- iOS（规划中）：网络与系统文件选择器，不申请相册/通讯录/定位等敏感权限。

## 六、异常处理

- 导入失败：确认文件格式与编码（TXT 建议 UTF-8）；AZW3/KFX 等加密格式请先用 Calibre 转为 EPUB。
- 翻页残影：在墨水屏设备开启"整屏刷新"。
- AI 无响应：检查网络与 API Key/接口地址配置。
