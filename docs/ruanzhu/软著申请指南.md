## 三、申请步骤（自办，零代理费）

1. 注册并完成**中国版权保护中心**实名认证（<https://www.ccopyright.com.cn> ，个人用身份证+银行卡/人脸）。
2. 在线填报《软件著作权登记申请表》（按上表）。
3. 上传材料：
   - 源程序：提交 `源代码整理.txt`（前30+后30页，每页≥50行，打印件或 PDF）；
   - 软件说明书：`用户手册.md` 转 PDF（≥10–15 页，含界面截图，截图在仓库 `docs/`）。
4. 提交并缴费（官费，见下）。
5. 等待审查，补正（如有），获证（电子证书）。

## 四、费用与周期（2024–2026 参考）

- **官费**：计算机软件著作权登记费约 **¥300/件**（不加急）。
- **代理费**：自办为 0；若找代理约 ¥600–1500（非必需，本方案为零成本自办）。
- **周期**：普通件约 **30–60 个工作日**；加急（另收费）可缩短至数个工作日。
- 最终以中国版权保护中心当期公示为准。

## 五、与"上架应用商店"的关系（重要）

软著**不是**上架华为/小米等国内商店的唯一前置，但强烈建议同步办理；真正硬性前置是 **App 备案（应用备案）**：

- 自 2023-09 起，在国内分发（含华为 AppGallery 中国区）的 App 必须完成**互联网信息服务 App 备案**（依托 ICP 备案主体）。
- 个人亦可备案（需已个人或单位 ICP 备案的域名）；企业则用公司 ICP 备案。
- 软著可作为权属证明加速备案；部分场景备案需提供软著或著作权声明。

因此上线时间线建议：

1. 先备齐本目录软著材料 → 提交软著（与备案可并行）；
2. 同步办理/确认 ICP 备案与 App 备案；
3. 在华为 AppGallery Connect 提交（见仓库内华为提交清单）；
4. iOS 需 Mac + Xcode + Apple Developer（¥688/年）另行构建。
