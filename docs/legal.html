红杉阅读

本地优先电子书阅读器 · 隐私政策 / 用户协议 / 权限说明

生效日期：2026-11-04

红杉阅读（以下简称"本应用"）是一款本地优先的电子书阅读器。我们极其重视你的隐私，并遵循"数据最小化"原则。本政策说明我们如何处理信息。

一、我们收集的信息

本应用默认完全在你的设备本地运行，不要求注册账号，不收集任何个人信息即可使用核心阅读功能。保存在你设备上的数据仅包括：导入的书籍文件、阅读进度与书签、排版与主题等设置，以及在你主动启用 AI 功能时保存的第三方 API Key（仅存本机）。这些数据均保存在你的设备本地存储/应用沙盒中，不会自动上传到任何服务器（本应用没有后端服务器）。

二、AI 与联网功能

当你主动开启"AI 引擎"或"翻译"并填入第三方提供方的 API Key 后，阅读页的"译 / AI 解释"、AI 助手（导读 / 问答 / 笔记 / 双语对照）会将你选中的文本或本书内容发送给你所配置的大模型 / 翻译服务（如 DeepL、Google、OpenAI 及兼容接口）。这些数据由对应第三方按其各自隐私政策处理，传输与存储责任由该提供方承担。你随时可在设置中关闭 AI 功能并清除 Key，关闭后相关联网行为即停止。

三、网络权限

本应用申请"网络"权限，仅用于上述 AI / 翻译请求以及极少量的版本检查；书籍导入、阅读、笔记均不依赖网络。

四、我们不会出售或共享你的个人信息

除法律法规要求或你主动开启的第三方服务外，我们不会向任何第三方披露、出售或交易你的数据。

五、儿童隐私

本应用不专门面向未满 14 周岁的儿童，我们不会有意收集儿童个人信息。

六、你的权利

你可以随时通过卸载应用，或在系统设置中清除应用数据，来删除全部本地数据。

七、政策变更

如本政策发生变更，我们将在应用内更新并以最新版本为准。

八、联系我们

如你对隐私事宜有疑问，可通过邮箱 sequoia-dev@example.com 联系我们。

Android

  • 网络（INTERNET）：仅用于 AI / 翻译请求与版本检查，不用于收集个人数据；关闭 AI 功能后基本不触发联网。

iOS（如后续版本上架）

  • 网络：同上，用于 AI / 翻译与版本检查。

我们不申请的权限

本应用不申请相机、定位、通讯录、麦克风、电话、短信等敏感权限；所有核心阅读与笔记功能均可在不授权任何敏感权限的情况下离线使用。
