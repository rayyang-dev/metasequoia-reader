# 水杉阅读 · 能力路线图 100 项（v1.2.0 起）

> 组织方式：**10 个能力簇 × 10 项**。顶级产品团队不会把 100 个点做成 100 个孤立开关，
> 而是先归并成若干「能力系统」，一整套数据结构 + 一套 UI + 一组行为契约覆盖多个点。
> 优先级：P0 = 体验硬伤 / 高频，P1 = 明显提效，P2 = 长尾或依赖外部条件。
>
> 本轮落地状态见文末「落地矩阵」。**未落地项明确标注原因，绝不做「点了没反应」的假开关。**
