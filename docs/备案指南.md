> 域名 `shanwood.cn` 已注册，按 `docs/域名落地清单.md` 解析到 Cloudflare Pages（境外托管），依法无需备案。

## 零、两者关系（先搞清，避免走弯路）
- **ICP 备案（网站备案）**：给你的**域名/网站**在工信部备个案，拿到备案号（如 `京ICP备2026XXXX号`）。
- **App 备案（移动应用备案）**：给你的 **App** 在工信部备个案（如 `京ICP备2026XXXX号-11A`）。
- **关键依赖**：App 备案必须以 ICP 备案**主体/域名**为前提——你先要有个 ICP 备案的域名，才能把 App 挂上去备案。
- 顺序：**先 ICP 备案 → 再 App 备案**。两者都免费（政府不收费，云服务商免费代办），只有域名本身要钱（约 ¥50–100/年）。

## 一、ICP 备案（先做，约 1–20 工作日）
1. **买一个域名**（本项目已完成：`shanwood.cn`，2026-11-11，首年 ¥14）：在阿里云 / 腾讯云 / 华为云 选 `.cn` 或 `.com`，年费约 ¥50–100。国内注册商**必须先实名认证**，否则 Serverhold 暂停解析。
2. **进入云服务商的"备案"流程**：他们会引导真实性核验（人脸 / 幕布照）。
3. **准备材料**：
   - 个人：身份证 + 人脸核验；
   - 企业：营业执照 + 法人/负责人核验。
4. **填写信息**：主体信息、网站信息（网站名称、域名、服务内容选"单位门户/个人博客"或"其他"）、域名证书。
5. **提交**：云服务商初审（1–3 天）→ 省通信管理局审核（约 1–20 工作日）→ 拿到 ICP 备案号。
6. **备案成功后**：把域名解析到任意国内可访问的静态托管，并**启用 HTTPS**。
   - ⚠️ **重点**：隐私政策页（`docs/legal.html`）必须部署在**这个已备案域名**下（见第三节坑点）。

> 个人备案即可，流程最简单；若以后要商业化 / 对公，再转企业备案。

## 二、App 备案（ICP 完成后做，约 1–20 工作日）
1. 在 **beian.miit.gov.cn** 或云服务商"App 备案"入口，选择已有 ICP 备案主体，新增"移动应用"。
2. **填写**：
   - 应用名称：**红杉阅读**（与商店一致）；
   - 包名：`com.rayyang.metasequoia`；
   - 运行平台：先 Android，iOS 后补；
   - 服务内容 / 类目：**阅读 / 电子书**；
   - **隐私政策 URL**：必须指向你那个**已 ICP 备案的域名**（如 `https://sequoia.shanwood.cn/legal.html`），不能是 `*.github.io` 等未备案域名；
   - 应用图标、截图、后台服务域名（本地优先 App 无后端也照填你的备案域名）；
   - 实名 / 主体信息。
3. **提交**：接入商初审 → 管局审核 → 拿到 App 备案号。
4. **备案通过后**：在 **App 内（启动页 / 关于 / 设置页脚）和隐私政策页底部展示备案号**（合规硬性要求）。

## 三、关键坑（务必注意）
- ❗ **隐私政策域名必须 ICP 备案**：GitHub Pages（`*.github.io`）域名未备案，App 备案会被打回。因此不要只把 `legal.html` 放 GitHub Pages——需**同时部署到你的备案域名**，用备案域名作为隐私 URL。
  - ⚠️ **本项目已改走单机豁免路线**（见顶部路线变更）：App 备案不再办理，`*.github.io` 与 `sequoia.shanwood.cn` 均可作为隐私 URL；本条坑点仅在恢复备案路线时重新适用。
- **备案号要展示**：App 内（设置/关于页脚）+ 隐私政策页底部都要有备案号。
- **个人备案 ≠ 经营性**：纯阅读/工具、不接内购变现，个人备案足够；一旦接支付/广告变现，需另办 **ICP 经营许可证（EDI/ICP 证）**，那是另一套、难度更高。
- **iOS 中国区**：Apple 上架中国区目前也要求提供备案号，所以这步建议一并办（即便主要想上 iOS）。

## 四、时间线（最快路径）
- 域名购买 + ICP 备案：约 **1–3 周**；
- App 备案：约 **1–3 周**（与商店提交可并行准备材料）；
- 合计约 **1–2 个月**——这才是"最快上线"的真正瓶颈，不是打包。

## 五、成本
- 域名：¥50–100/年；
- ICP 备案 + App 备案：政府不收费，云服务商免费代办；
- 远低于软著代理费，且是上架国内商店的**硬性前置**。
