> ✅ **范围结论（2026-11-11 核实）**：**Cloudflare、自有域名、官网都不是上架前置**，可以整条跳过。两个商店唯一强制的网址类材料是「公开可访问的 HTTPS 隐私政策 URL」——GitHub Pages 即可，0 元、免备案。`docs/域名落地清单.md` 与 `site/` 属于上架后的品牌增强，不阻塞送审。

## 一、现有包

- Release 包：`android/app/build/outputs/apk/release/Sequoia-release.apk`（已存在）
- 包名：`com.rayyang.metasequoia`
- ⚠️ 注意：该包构建于今日"宣纸背景/三主题"改动**之前**。若你想让上架版本包含最新主题，请先 `cap copy android` 后重新 `./gradlew assembleRelease` 再提交；否则可直接用现有包试提交。

## 二、硬性前置（提交前务必具备）

1. **华为开发者账号**：注册并实名认证 AppGallery Connect（https://developer.huawei.com/consumer/cn/agconnect/）。个人/企业均可。
2. **隐私政策 URL**（唯一强制的网址类材料）：
   - ✅ **主选：GitHub Pages** `https://rayyang-dev.github.io/sequoia-reader/legal.html`。内容真源 `docs/legal.html` 已在仓库；在 GitHub 仓库 **Settings → Pages → Source 选 `main` 分支 / `/docs` 目录**，一个开关即可，免费、自带 HTTPS、无需域名、无需 Cloudflare、无需备案。
   - 华为 AGC 与 App Store Connect 都只要求「公开可访问、无需登录、HTTPS、返回 200、地址稳定」，**不指定托管方**；`*.github.io` 被明确接受（Apple Guideline 5.1.1 常见解法）。
   - ⚠️ 华为 AGC 的标准化「隐私托管 / 协议服务」**目前主要面向 HarmonyOS 应用与元服务，Android 应用通常仍需自行提供 URL**，不要把它当可靠依赖；若 AGC 里能看到「协议服务 → 新建协议 → 生成链接」入口可顺手试，能生成就省事。
   - 可选增强：自有域名 `https://sequoia.shanwood.cn/legal.html`（见 `docs/域名落地清单.md`）。⚠️ `site/legal.html` 页脚含该正式域名链接，**域名未生效前不要拿它送审**。
   - ❗ **提交前必须修**：`docs/legal.html` 第 66 行联系邮箱仍是占位 `sequoia-dev@example.com`。Apple 要求隐私页有**真实可达的联系邮箱 + 主体名称**，占位邮箱会导致 5.1.1 被拒。换成你的真实邮箱后，`site/legal.html` 同步。
3. **备案与版权（路线已调整，2026-11-11）**：
   - 本项目走「**纯离线单机 APP**」路线：AGC「核准(备案)信息」勾选**单机 APP** 即可免 ICP / APP 备案；苹果侧纯离线 App 可申请 ICP 备案豁免。前提是 App 确实不联网（见 `www/js/release-gate.js` 与 `docs/备案指南.md` 顶部路线变更）。
   - 版权信息：华为 AGC 必填字段可用《免责函》（「本公司」改「本人」、签章改签名）0 元替代软著；软著官费本来就是 0，只是周期约 2–3 个月。
   - ❗ **单机 APP 判定风险（P1，比域名重要得多）**：华为官方口径是「APP 在完全无网络环境下，所有核心功能仍能正常使用」，且明确「勾选单机 APP 提交后，若识别到该应用存在联网场景，**将无法通过审核**」。本地核查发现 `www/js/ai.js` / `llm.js` / `translate.js` 含 `fetch()` 到 OpenAI / DeepL / Google Translate，`AndroidManifest.xml` 也声明了 `INTERNET` 权限。`www/js/release-gate.js` 已存在并被 `index.html` 引入、列入 `sw.js` ASSETS，**但送审前必须实测确认它真正隐藏且禁用了这些联网入口、不会发起任何请求**（官方允许「仅隐私协议页联网」仍算单机）。
   - ⚠️ 若审核仍要求备案号，再按 `docs/备案指南.md` 补办。
4. **应用签名**：Release 包所用签名密钥需由你保管；华为要求上传签名指纹（SHA-256）。若签名丢失需重新生成并可能换包名/账号。
5. **内容分级与资质**：阅读类 App 一般无特殊资质；按实际情况填写年龄分级（建议 3+ 或 12+）。

## 三、提交步骤（AppGallery Connect 控制台）

1. 创建应用：填写应用名称"红杉阅读"、包名 `com.rayyang.metasequoia`、分类"图书阅读"。
2. 上传 APK（`Sequoia-release.apk`），填写版本号（如 1.0.0 / 100）。
3. 填写：应用简介、截图（用 `docs/` 下的 `screen-*.png`）、图标（Android `mipmap/ic_launcher`）。
4. 填写隐私政策链接（见上）、权限声明（仅需说明"网络"用途，参考应用内"权限说明"）。
5. 内容分级问卷、付费/免费（建议免费）、上架地区（先选中国区）。
6. 提交审核 → 按华为反馈补正 → 上架。

## 四、iOS 侧前置（如后续要上架 App Store）

- ❗ **本仓库当前只有 `android/` 与 `harmony/`，没有 `ios/` 工程**（`capacitor.config.json` 也无 ios 配置）。上架 Apple 不是「填个表」：需先 `npx cap add ios`，再用 **Mac + Xcode** 构建归档。若想最快上架，**建议先只做华为**。
- 需 `cap add ios` 生成 iOS 工程；**Mac + Xcode** 构建；Apple Developer 会员 **$99/年（约 ¥688）**。
- App Store 需：隐私政策 URL（同上的 `legal.html`）、"隐私营养标签"（App Store Connect 内填写数据收集披露）、隐私权限用途字符串（如新增原生权限）。
- 法律页（隐私/协议/权限）已与本安卓版通用，无需重写，仅需在 App Store Connect 填 URL + 营养标签。

## 五、时间预估（最短上架路径，不含域名 / Cloudflare）

- 账号注册 + 实名：0.5–1 天
- 隐私 URL 上线（GitHub Pages 开一个开关）：约 5 分钟 —— 域名 ✅ 已实名，但**不需要用到**
- 修占位邮箱、验证 `release-gate.js` 无联网：约 30 分钟
- 单机 APP 勾选 / 免责函：即时（审核不确定性另计）
- 华为审核：约 1–3 个工作日/轮
- （可选）自有域名 + Cloudflare Pages：不阻塞上架，上架后再做

> **结论（2026-11-11 纠正）**：Cloudflare、域名、官网**都不是上架前置**，可整条跳过。真正的瓶颈是：① 华为开发者账号实名；② **单机 APP 联网检测是否过关**（`release-gate.js` 必须真正切断 AI / 在线翻译的 `fetch`）；③ 隐私政策页的占位邮箱必须换成真实邮箱；④ 若要做苹果，还需新建 `ios/` 工程 + Mac + ¥688/年会员。
> 建议顺序：**先只上华为** → 用 GitHub Pages 拿 URL → 跑通审核 → 再补 iOS 与官网。
