# 华为应用市场（AppGallery）上架清单 — 红杉 Sequoia

> 目标：用现有 Android 包**最快**试提交。本文件为"待办清单 + 前置条件"，上传动作需在华为控制台由你（或你的账号）完成。

## 一、现有包

- Release 包：`android/app/build/outputs/apk/release/Sequoia-release.apk`（已存在）
- 包名：`com.rayyang.metasequoia`
- ⚠️ 注意：该包构建于今日"宣纸背景/三主题"改动**之前**。若你想让上架版本包含最新主题，请先 `cap copy android` 后重新 `./gradlew assembleRelease` 再提交；否则可直接用现有包试提交。

## 二、硬性前置（提交前务必具备）

1. **华为开发者账号**：注册并实名认证 AppGallery Connect（https://developer.huawei.com/consumer/cn/agconnect/）。个人/企业均可。
2. **隐私政策 URL**：填 **`https://sequoia.shanwood.cn/legal.html`**（自有域名 `shanwood.cn` 已注册，站点文件见 `site/`，部署步骤见 `docs/域名落地清单.md`）。备用：华为 AGC「协议服务」生成的制式隐私政策（0 元），或 GitHub Pages `https://rayyang-dev.github.io/sequoia-reader/legal.html`。走单机豁免路线时后者也可用。内容真源为 `docs/legal.html`，改条款时须同步 `site/legal.html`。
3. **备案与版权（路线已调整，2026-11-11）**：
   - 本项目走「**纯离线单机 APP**」路线：AGC「核准(备案)信息」勾选**单机 APP** 即可免 ICP / APP 备案；苹果侧纯离线 App 可申请 ICP 备案豁免。前提是 App 确实不联网（见 `www/js/release-gate.js` 与 `docs/备案指南.md` 顶部路线变更）。
   - 版权信息：华为 AGC 必填字段可用《免责函》（「本公司」改「本人」、签章改签名）0 元替代软著；软著官费本来就是 0，只是周期约 2–3 个月。
   - ⚠️ 若审核仍要求备案号，再按 `docs/备案指南.md` 补办，并把隐私 URL 换到已备案域名。
4. **应用签名**：Release 包所用签名密钥需由你保管；华为要求上传签名指纹（SHA-256）。若签名丢失需重新生成并可能换包名/账号。
5. **内容分级与资质**：阅读类 App 一般无特殊资质；按实际情况填写年龄分级（建议 3+ 或 12+）。

## 三、提交步骤（AppGallery Connect 控制台）

1. 创建应用：填写应用名称"红杉阅读"、包名 `com.rayyang.metasequoia`、分类"图书阅读"。
2. 上传 APK（`Sequoia-release.apk`），填写版本号（如 1.0.0 / 100）。
3. 填写：应用简介、截图（用 `docs/` 下的 `screen-*.png`）、图标（Android `mipmap/ic_launcher`）。
4. 填写隐私政策链接（见上）、权限声明（仅需说明"网络"用途，参考应用内"权限说明"）。
5. 内容分级问卷、付费/免费（建议免费）、上架地区（先选中国区）。
6. 提交审核 → 按华为反馈补正 → 上架。

## 四、iOS 侧前置（如后续要上架 App Store）

- 需 `cap add ios` 生成 iOS 工程；**Mac + Xcode** 构建；Apple Developer 会员 **$99/年（约 ¥688）**。
- App Store 需：隐私政策 URL（同上的 `legal.html`）、"隐私营养标签"（App Store Connect 内填写数据收集披露）、隐私权限用途字符串（如新增原生权限）。
- 法律页（隐私/协议/权限）已与本安卓版通用，无需重写，仅需在 App Store Connect 填 URL + 营养标签。

## 五、时间预估（最快路径）

- 账号注册+实名：0.5–1 天
- 域名实名认证：1–3 工作日（Serverhold 解除）
- 隐私 URL 上线（Cloudflare Pages 自定义域）：NS 生效后约 10 分钟
- 单机豁免勾选 / 免责函：即时（审核不确定性另计）
- 华为审核：约 1–3 个工作日/轮

> 结论：按零成本路线，瓶颈是**账号实名 + 域名实名 + 单机豁免是否被认可**，不是打包或备案。建议并行启动：① 域名实名并把 `shanwood.cn` 接入 Cloudflare（见 `docs/域名落地清单.md`）；② 注册并实名华为开发者账号；③ 部署 `site/` 拿到正式隐私政策 URL。
